# NanoByte.Common

**NanoByte.Common** provides various utility classes and data structures with an emphasis on:

- integration with native Windows and Linux features,
- network and disk IO,
- advanced collections and
- undo/redo logic.

[API documentation](https://common.nano-byte.net/)

## Related packages

- [NanoByte.Common.AnsiCli](https://www.nuget.org/packages/NanoByte.Common.AnsiCli) adds ANSI console output.
- [NanoByte.Common.WinForms](https://www.nuget.org/packages/NanoByte.Common.WinForms) adds various Windows Forms controls.
- [NanoByte.Common.EtoForms](https://www.nuget.org/packages/NanoByte.Common.EtoForms) adds cross-platform GUI controls.
