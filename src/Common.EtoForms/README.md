# NanoByte.Common.EtoForms

**NanoByte.Common.EtoForms** builds upon [NanoByte.Common](https://www.nuget.org/packages/NanoByte.Common) and adds cross-platform GUI controls with an emphasis on progress reporting. Powered by [Eto.Forms](https://github.com/picoe/Eto).

[API documentation](https://common.nano-byte.net/)

## Related packages

- [NanoByte.Common.AnsiCli](https://www.nuget.org/packages/NanoByte.Common.AnsiCli) adds ANSI console output.
- [NanoByte.Common.WinForms](https://www.nuget.org/packages/NanoByte.Common.WinForms) adds various Windows Forms controls.
