# NanoByte.Common.WinForms

**NanoByte.Common.WinForms** builds upon [NanoByte.Common](https://www.nuget.org/packages/NanoByte.Common) and adds various Windows Forms controls with an emphasis on:

- progress reporting and
- data binding.

[API documentation](https://common.nano-byte.net/)

## Related packages

- [NanoByte.Common.AnsiCli](https://www.nuget.org/packages/NanoByte.Common.AnsiCli) adds ANSI console output.
- [NanoByte.Common.EtoForms](https://www.nuget.org/packages/NanoByte.Common.EtoForms) adds cross-platform GUI controls.
